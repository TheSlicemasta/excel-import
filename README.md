# Система импорта Excel-заявок (Laravel 13 + Vue 3 Inertia)

Веб-приложение для загрузки больших файлов `*.xlsx` в базу данных MySQL с автоматическим фоновым парсингом, предотвращающим таймауты сервера (`max_execution_time`), динамическим созданием таблиц, автообновлением статусов (Polling) и пагинацией.

---

## Локальный запуск проекта

Для полноценной работы системы в локальном окружении необходимо запустить **три параллельных процесса** в разных окнах терминала.

### 1. Запуск бэкенд-сервера (Laravel)
Встроенный веб-сервер Artisan отвечает за обработку HTTP-запросов, маршрутизацию Inertia.js и отдачу данных.

* **Команда для запуска:**
  ```bash
  php artisan serve
  ```
* **Где открыть:** После запуска бэкенд будет доступен по адресу `http://127.0.0.1:8000/`.

---

### 2. Запуск фронтенда (Vite + Vue 3)
Сборщик Vite компилирует Vue-компоненты «на лету» (Hot Reload) и обеспечивает мгновенное отображение изменений интерфейса в браузере.

* **Команда для запуска:**
  ```bash
  npm run dev
  ```
* **Примечание:** Оставьте этот терминал открытым. Если вы вносили изменения во Vue, сборщик автоматически обновит страницу.

---

### 3. Запуск фонового обработчика очередей (Queue Worker)
Самый важный компонент для работы с большими файлами. Воркер берет задачи на парсинг из базы данных и выполняет их в фоновом режиме (потоковое чтение через `XMLReader`), что позволяет обходить лимит в 30 секунд.

* **Команда для запуска (с подробным логированием ошибок):**
  ```bash
  php artisan queue:work --verbose --tries=1
  ```
* **Важно:** Если вы вносите любые изменения в код фоновой задачи (`ImportExcelJob.php`), обязательно перезапустите воркер в терминале нажатием `Ctrl + C`, а затем выполните команду запуска заново.

---

## Дополнительные требования перед первым запуском

Если вы разворачиваете проект впервые, убедитесь, что:
1. В файле `.env` указано `QUEUE_CONNECTION=database`.
2. Применены все миграции: `php artisan migrate`.
3. В настройках вашего `php.ini` увеличены лимиты для загрузки больших файлов:
   ```ini
   post_max_size = 64M
   upload_max_filesize = 64M
   ```
