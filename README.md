# Система импорта Excel-заявок (Laravel 13 + Vue 3 Inertia)

Веб-приложение для загрузки больших файлов `*.xlsx` в базу данных MySQL с автоматическим фоновым парсингом, предотвращающим таймауты сервера (`max_execution_time=30`), динамическим созданием таблиц, автообновлением статусов (Polling) и пагинацией.

---

## 1. Первичная установка и настройка проекта

Если вы только что склонировали репозиторий или разворачиваете проект с нуля, выполните следующие шаги:

### Шаг 1: Установка зависимостей бэкенда
```bash
composer install
```

### Шаг 2: Установка зависимостей фронтенда
```bash
npm install
```

### Шаг 3: Настройка окружения
Создайте файл `.env` на основе шаблона:
```bash
cp .env.example .env
```
Сгенерируйте ключ приложения:
```bash
php artisan key:generate
```

### Шаг 4: Настройка конфигурации `.env`
Откройте файл `.env` и укажите параметры подключения к вашей пустой базе данных **MySQL**, а также переключите драйвер очередей:
```ini
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=excel_import_db
DB_USERNAME=root
DB_PASSWORD=your_password

QUEUE_CONNECTION=database
```

### Шаг 5: Применение миграций
Создайте системные таблицы (включая таблицы очередей `jobs` и метаданных `files`):
```bash
php artisan migrate
```

### Шаг 6: Настройка лимитов в `php.ini`
Для успешной загрузки файлов размером более 8 МБ найдите ваш рабочий файл конфигурации `php.ini` и увеличьте лимиты:
```ini
post_max_size = 64M
upload_max_filesize = 64M
```
*После изменения `php.ini` обязательно перезапустите ваш локальный веб-сервер.*

## 2. Структура базы данных (MySQL)

Система использует гибридный подход: общая таблица метаданных + изолированная динамическая таблица под каждый импортированный файл.

### Таблица `files` (Метаданные загрузок)
Эта таблица регистрирует факт загрузки, хранит оригинальные имена файлов, JSON-структуру заголовков и статус фоновой обработки.

| Поле | Тип данных | Описание |
| :--- | :--- | :--- |
| `id` | `BIGINT UNSIGNED` | Первичный ключ (автоинкремент). |
| `original_name` | `VARCHAR(255)` | Исходное имя файла (например, `orders_2026.xlsx`). |
| `table_name` | `VARCHAR(255)` | Уникальное имя динамической таблицы в БД (например, `import_file_original_file_name_1717320000`). |
| `status` | `VARCHAR(255)` | Статус задачи: `processing` (в очереди/обработка), `completed` (успешно), `failed` (ошибка). |
| `created_at` | `TIMESTAMP` | Дата и время загрузки файла. |
| `updated_at` | `TIMESTAMP` | Дата и время последнего изменения статуса. |

### Динамические таблицы (`import_file_[originalFileName]_[timestamp]`)
Создаются автоматически воркером в момент начала парсинга. Количество колонок соответствует количеству заполненных ячеек в первой строке Excel-файла.
* `col_0`, `col_1`, `col_2`... `col_n` (Тип `TEXT`, nullable) — Колонки данных ячеек.

При удалении файла через интерфейс динамическая таблица полностью удаляется из MySQL (`DROP TABLE`), очищая дисковое пространство.

## 3. Локальный запуск проекта

Для полноценной работы системы в локальном окружении необходимо запустить **три параллельных процесса** в разных окнах терминала.

### 3.1 Запуск бэкенд-сервера (Laravel)
Встроенный веб-сервер Artisan отвечает за обработку HTTP-запросов и маршрутизацию Inertia.js.
```bash
php artisan serve
```
* **Адрес страницы импорта:** `http://127.0.0.1:8000/`

### 3.2 Запуск фронтенда (Vite + Vue 3)
Сборщик Vite компилирует Vue-компоненты «на лету» (Hot Reload) при сохранении изменений.
```bash
npm run dev
```

### 3.3 Запуск воркера очередей (Queue Worker)
Извлекает задачи из таблицы `jobs` и производит потоковое чтение XLSX через `XMLReader` в фоновом режиме, расходуя не более 5-10 МБ ОЗУ.
```bash
php artisan queue:work --verbose --tries=1
```
* **Важно:** При внесении изменений в код фоновой задачи (`ImportExcelJob.php`) обязательно перезапустите воркер нажатием `Ctrl + C` и запустите команду заново.

## 4. Альтернативный запуск через Docker (Laravel Sail)

Если вы предпочитаете использовать Docker вместо локально установленных PHP и MySQL, вы можете запустить проект с помощью **Laravel Sail**.

### Шаг 1: Первичный запуск и сборка контейнеров
Запустите сборку Docker-окружения в фоновом режиме:
```bash
./vendor/bin/sail up -d
```
*Примечание: Если у вас на компьютере не установлен Composer, вы можете запустить установку зависимостей через временный Docker-контейнер: `docker run --rm -u "$(id -u):$(id -g)" -v "$(pwd):/var/www/html" -w /var/www/html lorisleiva/laravel-deployer:8.3 composer install`*

### Шаг 2: Выполнение команд внутри Docker
Все команды `php artisan` и `npm` теперь должны выполняться внутри контейнера приложения через утилиту `sail`:

```bash
# Генерация ключа (если не сделано)
./vendor/bin/sail artisan key:generate

# Запуск миграций внутри Docker
./vendor/bin/sail artisan migrate

# Установка фронтенд зависимостей и запуск Vite
./vendor/bin/sail npm install
./vendor/bin/sail npm run dev
```

### Шаг 3: Запуск воркера очередей в Docker
Чтобы Docker-контейнер начал обрабатывать ваши Excel-файлы в фоне, откройте новое окно терминала и запустите воркер внутри контейнера:

```bash
./vendor/bin/sail artisan queue:work --verbose --tries=1
```

### Полезные команды Sail:
* `./vendor/bin/sail stop` — остановить контейнеры без удаления данных.
* `./vendor/bin/sail down` — полностью остановить и удалить контейнеры сети.
* Приложение будет доступно по стандартному адресу: `http://localhost`.
